## 💾 Memory & Knowledge Systems

### 8. **MemPalace/mempalace**
- **Description:** Local-first AI memory with verbatim storage, pluggable backends, 96.6% R@5 raw on LongMemEval
- **Key Features:**
  - Verbatim text storage (no summarization/paraphrasing)
  - Structured memory (wings → people/projects, rooms → topics, drawers → content)
  - Semantic search with hybrid keyword/temporal boosting
  - Pluggable backends (ChromaDB default, SQLite, Qdrant, pgvector)
  - Knowledge graph with entity-relationship tracking
  - 29 MCP tools for palace management
  - Auto-save hooks for Claude Code
  - Multi-agent support with personal diaries
  - 96.6% recall (R@5) on LongMemEval - zero API calls
- **Support:** Claude Code, Codex CLI, Cursor, local models
- **GitHub:** https://github.com/MemPalace/mempalace
- **License:** MIT
- **Archive Path:** `repos/MemPalace_mempalace/`
- **Python:** 3.9+
- **Benchmarks:** LongMemEval 96.6% raw, 98.4% hybrid, 80.3% MemBench
