# 创造与魔法攻略百科 - 产品需求文档

## 1. 产品概述

**创造与魔法攻略百科**是一个专为沙盒魔法游戏《创造与魔法》玩家打造的全方位攻略网站。整合好游快爆、B站雪落倾殇等权威渠道资源，涵盖地图资源采集坐标、生物饲料配方、食谱大全、生物植物图鉴、版本更新历史等核心内容，为玩家提供一站式学习与查询体验。

**目标用户**：创造与魔法游戏玩家，尤其是新手入门玩家和回归玩家
**核心价值**：聚合权威攻略资源，提供清晰的版本演进脉络，便于玩家快速上手和深入研究

---

## 2. 功能模块

### 2.1 页面结构

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | Hero区域 | 全屏魔法森林背景动画，展示核心导航入口 |
| 首页 | 快速导航 | 四大核心功能卡片：地图资源、生物饲料、食谱大全、图鉴 |
| 首页 | 最新攻略 | 版本更新与攻略列表 |
| 地图资源 | 地图选择器 | 可视化地图列表，支持切换不同地图 |
| 地图资源 | 采集物列表 | 按资源类型分类展示采集物坐标与详情 |
| 生物饲料 | 饲料配方 | 各类生物的饲料配方与制作方法 |
| 食谱大全 | 食谱列表 | 完整食谱配方，按食物类型分类 |
| 生物图鉴 | 生物卡片 | 所有生物信息卡片，支持筛选与搜索 |
| 植物图鉴 | 植物卡片 | 所有植物信息卡片，支持筛选与搜索 |
| 版本历史 | 时间轴 | 完整版本演进时间轴 |
| 版本历史 | 版本详情 | 每个版本的更新内容与攻略 |
| 关于我们 | 致谢 | 数据来源说明与版权信息 |

### 2.2 核心功能

1. **可视化地图资源系统**
   - 地图缩略图展示
   - 采集物分类（矿石、植物、动物、特殊资源）
   - 坐标精确定位
   - 采集物详情弹窗

2. **智能搜索与筛选**
   - 全文搜索
   - 按类型、稀有度、地图筛选
   - 收藏功能

3. **版本时间轴导航**
   - 可视化版本演进
   - 版本间差异高亮
   - 新增/删除内容标注

## 3. 设计风格

### 3.1 视觉方向

**魔法森林幻想风格** — 融合梦幻与自然元素，营造沉浸式魔法世界氛围

### 3.2 色彩系统

| 用途 | 颜色 | Hex |
|-----|------|-----|
| 主色-魔法紫 | 深邃紫 | `#6B21A8` |
| 主色-精灵绿 | 森林绿 | `#166534` |
| 强调色-金箔 | 魔法金 | `#EAB308` |
| 背景-暗夜 | 午夜蓝黑 | `#0F172A` |
| 背景-次级 | 雾霭紫 | `#1E1B4B` |
| 文字-主级 | 雪白 | `#F8FAFC` |
| 文字-次级 | 银灰 | `#94A3B8` |
| 卡片背景 | 玻璃紫 | `rgba(139, 92, 246, 0.1)` |

### 3.3 字体选择

- **标题字体**: `"Cinzel Decorative", "STKaiti", serif` — 优雅魔法感
- **正文字体**: `"Noto Sans SC", "PingFang SC", sans-serif` — 清晰易读
- **数字/坐标**: `"JetBrains Mono", monospace` — 精确感

### 3.4 动效设计

- **iOS风格过渡**: 300ms ease-out 基础过渡
- **弹性动画**: cubic-bezier(0.68, -0.55, 0.265, 1.55) 弹性效果
- **滚动视差**: 背景层与内容层不同滚动速度
- **悬浮高亮**: 卡片hover时微微上浮 + 光晕效果
- **页面切换**: 淡入淡出 + 轻微缩放

### 3.5 组件样式

- **卡片**: 圆角16px，玻璃拟态效果，微妙的边框光晕
- **按钮**: 圆角12px，渐变背景，hover时发光
- **导航**: 毛玻璃效果背景，滚动时加深
- **图片**: 圆角8px，hover时轻微放大

## 4. 技术架构

### 4.1 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式方案**: Tailwind CSS 3 + 自定义CSS变量
- **路由管理**: React Router DOM 6
- **状态管理**: Zustand
- **图标库**: Lucide React
- **动画方案**: Framer Motion

### 4.2 页面路由

| 路由 | 页面 |
|-----|------|
| `/` | 首页 |
| `/map` | 地图资源采集 |
| `/feed` | 生物饲料配方 |
| `/recipes` | 食谱大全 |
| `/creatures` | 生物图鉴 |
| `/plants` | 植物图鉴 |
| `/versions` | 版本历史 |
| `/versions/:versionId` | 版本详情 |

## 5. 数据结构

### 5.1 地图数据

```typescript
interface MapData {
  id: string;
  name: string;
  description: string;
  image: string;
  resources: Resource[];
}
```

### 5.2 采集物数据

```typescript
interface Resource {
  id: string;
  name: string;
  type: 'ore' | 'plant' | 'animal' | 'special';
  rarity: 'common' | 'rare' | 'epic' | 'legendary';
  coordinates: { x: number; y: number };
  mapId: string;
  description: string;
  icon: string;
}
```

### 5.3 版本数据

```typescript
interface Version {
  id: string;
  versionNumber: string;
  releaseDate: string;
  title: string;
  added: string[];      // 新增内容
  removed: string[];     // 删除内容
  changed: string[];     // 变更内容
  guide: string;          // 攻略正文
}
```
